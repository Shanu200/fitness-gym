# 💪 Fitness Gym Web App

## 📌 Project Description

A modern fitness gym web application built using React and Next.js. This platform allows users to explore gym services, Trainers,Contact,choosing plane and interact with a clean and responsive UI.

---

## 🛠️ Tech Stack

* ⚛️ React.js
* ▲ Next.js (App Router)
* 🎨 Tailwind CSS
* 🌐 JavaScript
* 📦 Node.js

---

## ⚙️ Setup Instructions

### 1️⃣ Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPO.git
```

### 2️⃣ Navigate to project folder

```bash
cd fitness-gym
```

### 3️⃣ Install dependencies

```bash
npm install
```

### 4️⃣ Run the development server

```bash
npm run dev
```

### 5️⃣ Open in browser

```bash
http://localhost:3000
```
